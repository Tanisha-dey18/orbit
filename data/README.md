# data/

| Path | Contents | In Git? |
|---|---|---|
| `samples/` | 3 **synthetic** before/after pairs + exact ground truth + `manifest.json`, generated by `backend/scripts/make_samples.py`. Not real satellite imagery. | yes (small) |
| `checkpoints/` | Trained model weights, e.g. `orbit_fc_siam_diff.pt` (path set by `ORBIT_MODEL_PATH`). **Empty by default**: no trained model is bundled. | no |
| `datasets/` *(create it yourself)* | Downloaded datasets such as LEVIR-CD. Large and licence-restricted. | no |
| `synthetic_cd/` *(optional)* | Smoke-test dataset from `prepare_dataset.py synthetic`. | no |

See `docs/dataset.md` for dataset access, structure and licensing, and `docs/model_card.md` for training.
